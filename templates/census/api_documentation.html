Getting Started

The API is read-only and does not require authentication. All endpoints are accessible via HTTP GET requests. The base URL for all API endpoints is:

{{ api_base_url }}

Responses are returned in JSON format. For large datasets, always use filters to limit results.

API Root

Visit the API root to see a summary of all available endpoints with links:

{{ api_base_url }}

Denominations

Access denomination taxonomy and family classifications from the 1926 Census.

GET /census/api/denominations/

Returns a paginated list of all denominations with their family classifications.

Query Parameters

Parameter Type Description
family_census string Filter by census family (e.g., "Baptist bodies")
family_relec string Filter by Religious Ecologies family classification
search string Search denomination names
Try it: {{ api_base_url }}denominations/
GET /census/api/denominations/families/

Returns unique denomination families with counts. Only includes families that have location data available.

Example Response
{ "census_families": [ {"name": "Baptist bodies", "count": 24}, {"name": "Methodist bodies", "count": 18} ], "relec_families": ["Baptist", "Methodist", "Catholic"] }
Try it: {{ api_base_url }}denominations/families/
GET /census/api/denominations/by_family/

Returns denominations grouped by family. Only includes denominations with location data.

Query Parameters

Parameter Type Description
family_census string Filter to specific census family
Try it: {{ api_base_url }}denominations/by_family/?family_census=Baptist+bodies

Religious Bodies (Congregations)

Access individual congregation records from the 1926 Census. Note: Use filtered endpoints to avoid large responses

GET /census/api/religious-bodies/ Use filters!

Returns detailed congregation records. This endpoint can return large amounts of data. We recommend using the specialized endpoints below instead.

Query Parameters

Parameter Type Description
denomination integer Filter by denomination ID
search string Search name, address, or census code
limit integer Limit number of results
Try it: {{ api_base_url }}religious-bodies/?limit=10
GET /census/api/religious-bodies/map_data/ Recommended for maps

Lightweight endpoint optimized for map marker display. Returns only essential fields (id, name, lat, lon, denomination, total_members). Limited to 2,000 records.

Query Parameters

Parameter Type Description
family_census string Filter by census family
denomination integer Filter by denomination ID
bounds string Bounding box as "south,west,north,east"
Try it: {{ api_base_url }}religious-bodies/map_data/?family_census=Baptist+bodies
GET /census/api/religious-bodies/demographics_data/

Extended endpoint that includes detailed membership demographics: male/female members, age breakdowns, and educational program enrollment. Limited to 2,000 records.

Response Fields

  • male_members, female_members - Gender breakdown
  • members_under_13, members_13_and_older - Age breakdown
  • sunday_school_scholars - Sunday school enrollment
  • parochial_elementary_scholars, parochial_secondary_scholars - Parochial school enrollment
Try it: {{ api_base_url }}religious-bodies/demographics_data/

GeoJSON Endpoints

GeoJSON-formatted data for use with mapping libraries (Leaflet, Mapbox, D3, etc.).

GET /census/api/religious-bodies/geojson/

Returns a GeoJSON FeatureCollection with Point features for each congregation. Each feature includes congregation details in properties.

Query Parameters

Parameter Type Description
family_census string Filter by census family (supports multiple)
family_relec string Filter by RelEc family
denomination integer Filter by denomination ID (supports multiple)
exclude_families string Comma-separated families to exclude
transcription_status string Filter by transcription status (e.g., "approved")
bounds string Bounding box as "south,west,north,east"
limit integer Max features (default: 2000, max: 5000)
Example Response
{ "type": "FeatureCollection", "features": [ { "type": "Feature", "geometry": { "type": "Point", "coordinates": [-77.0369, 38.9072] }, "properties": { "id": 1234, "congregation_name": "First Baptist Church", "denomination": "Southern Baptist Convention", "family_census": "Baptist bodies", "city": "Washington", "county": "District of Columbia", "state": "DC", "num_edifices": 1, "edifice_value": 50000 } } ] }
Try it: {{ api_base_url }}religious-bodies/geojson/?family_census=Methodist+bodies&limit=100
GET /census/api/religious-bodies/places_geojson/

Returns GeoJSON aggregated by populated place (city/town). Each feature represents a location with all congregations at that location grouped together. Useful for cluster maps or place-based analysis.

Feature Properties

  • location_id - Unique location identifier
  • populated_place, city, county, state - Location details
  • congregation_count - Number of congregations at this location
  • denominations - Array of unique denomination names
  • congregations - Array of congregation details
Try it: {{ api_base_url }}religious-bodies/places_geojson/?limit=50

Aggregation Endpoints

Pre-aggregated data for analysis and visualization.

GET /census/api/religious-bodies/city_membership/

Returns city-level membership aggregations. Each city includes total members, congregation counts, and list of denominations present.

Query Parameters

Parameter Type Description
year integer Census year (only 1926 supported)
denomination string Filter by exact denomination name
denominationFamily string Filter by family_relec value
Example Response
[ { "city": "New York", "state": "NY", "county": "New York", "lat": 40.7128, "lon": -74.0060, "total_members": 125000, "congregations": 450, "denominations_count": 35, "denominations": ["Baptist", "Catholic", "Methodist", ...] } ]
Try it: {{ api_base_url }}religious-bodies/city_membership/
GET /census/api/religious-bodies/denomination_families/

Returns comprehensive list of denomination families with counts of denominations and congregations in each family. Includes both census families and Religious Ecologies families.

Example Response
{ "census_families": [ { "name": "Baptist bodies", "denominations": 24, "congregations": 1500, "total_congregations": 2000, "has_location_data": true } ], "relec_families": [ { "name": "Baptist", "denominations": 24, "congregations": 1500, "has_location_data": true } ] }
Try it: {{ api_base_url }}religious-bodies/denomination_families/

Usage Tips

Best Practices

  • Always use filters to limit results and improve response times
  • Use map_data/ or city_membership/ instead of the raw religious-bodies/ list
  • Add ?limit=10 to test queries before running full requests
  • GeoJSON endpoints are optimized for mapping applications
  • City membership endpoint aggregates data by location for analysis

Example: Mapping Baptist Churches in Virginia

# Get GeoJSON for Baptist congregations GET {{ api_base_url }}religious-bodies/geojson/?family_census=Baptist+bodies&bounds=36.5,-83.6,39.5,-75.2 # Get city-level aggregations for Baptists GET {{ api_base_url }}religious-bodies/city_membership/?denominationFamily=Baptist

CORS

The API supports CORS (Cross-Origin Resource Sharing) for client-side JavaScript applications. You can make requests directly from browser-based applications.

Rate Limiting

There are currently no rate limits on the API, but please be considerate with your requests. Cache responses where appropriate and avoid making unnecessary repeated requests.

Questions about the API? Contact the Religious Ecologies project team.
